空战太刀的地面派生可用特殊纳刀、小居合、大居合和见切，并显示增幅护腕。拔刀时按 R＋B 进入特殊纳刀，架势就绪后按 X 出小居合，按 R 出大居合。攻击收招窗口按 R＋A 出见切。单机待机时点按 ZR 后松开可切换增幅。空中和落地仍按空战专用派生窗口处理。

使用 R／ZR 互换补丁时，上述 R 改用 ZR，单机增幅键改用 R。

强袭和炼金的主要新增招式沿用公会键位，可用特殊纳刀、居合、见切、气刃突刺、集中突刺、蓄力及移动气刃斩、赤刃连段和增幅护腕。两种风格保留三个狩技栏，支持狩技与新招互接。

强袭保留原生后撤斩，炼金保留原生左右移动斩。炼金的原生气刃三后点按 R 接原生气刃大回旋，命中按原生规则积攒炼金槽，长按 R 可接蓄力大回旋。炼金翻滚中 R＋Y 留给炼金桶，站定或挥刀时按住集中键再按 R＋Y 出集中突刺。

使用 R／ZR 互换补丁时，用 ZR 代替上述 R。

空战太刀踩怪后保留原生空中气刃三。松开 R 再短按一次，可把大回旋缓冲到落地后发动，持续按住 R 只执行空中气刃。拔刀时在空中提前按 R＋B 可落地接特殊纳刀。提前按 R＋Y 并保持集中模式到落地，可接集中突刺。踩怪、从台阶跳落和踩空后实际腾空都适用这两个落地组合键。

武士道追斩与无双斩收招可提前输入特殊纳刀、气刃突刺、集中突刺和光辉纳刀。解放斩三段伤害结束后可衔接普通斩、突刺、翻滚或气刃斩，带方向短按可接移动气刃斩，长按接蓄力。气刃突刺空挥后可提前缓冲翻滚。

武士道大居合成功反击后，按 R 接原生追斩，松开再按 R 接原生无双斩。无双斩消耗 25 点练气。精准回避后的 X → R 仍接练气解放斩，消耗一档刃色。武士道关闭普通和蓄力气刃大回旋。

武士道太刀保留原生精准回避和 X 反击斩。反击斩后按 R 可接练气解放斩，发动消耗一档刃色，收招保持拔刀。无刃色时只完成原生反击斩。保留公会式的特殊纳刀、居合开刃、增幅护腕和光辉纳刀。普通见切与红刃见切均关闭。

荒野太刀 · 凌越扩展 v0.353 兼容版

适用游戏是《Monster Hunter Generations Ultimate》1.4.0，Title ID 0100770008DD8000。请先准备已能在该环境加载插件的 MHGU Forge 1.5.1，并留一套有效的 Forge 前置。

Eden 模拟器

1. 关闭游戏，在 Eden 中右键 GU，打开模组数据目录。
2. 将旧 Wilds-LS-World 移出模组目录备份，再放入测试包内的整个 Wilds-LS-World 文件夹。
3. 启动游戏并在模拟器日志中检查 Forge 是否初始化了 mhw_ls_rebuild.nro。Eden 0.2.1 测试用的硬件兼容 Forge 构建为 1.5.1-gbbc540f。若 Eden 在系统键盘处停住，可将该游戏的 Software Keyboard Applet 设为 LLE 后重启。

v0.353 已完成 Eden 构建和附件校验。Eden 0.2.1 曾在公会太刀训练任务验证掌机与主机模式切换。增幅护腕、集中准星和 R3 提示会按当前游戏画面定位。

Ryujinx 1.3.3 请同时更新 v0.353 包内的插件与 w07.arc。插件包含集中居合转向兼容修复，动作档含公会风格特殊纳刀和见切的动画事件表修复。

Switch 实体机

1. 退出游戏并备份 SD 卡上现有的 atmosphere/contents/0100770008DD8000 目录。
2. 保留已经可用的 Forge 前置，把包内 atmosphere 文件夹合并到 SD 卡根目录。插件应位于 atmosphere/contents/0100770008DD8000/romfs/nativeNX/plugins/mhw_ls_rebuild.nro。
3. 回退时退出游戏并还原第 1 步的备份。Switch 实体机有进入集中模式、空挥居合或见切时闪退的报告，目前仍在排查。

v0.275 修复 Forge 受击和伤害显示钩子与太刀的共载问题。已装 v0.274 时，可只替换 mhw_ls_rebuild.nro。默认键位用完整包内的插件，互换键位用同版本 Switch 补丁「启用补丁」内的插件。Forge 日志中出现 [ml-rebuild] installed 或 R/ZR combat swap enabled 才表示控制器已启用。

若装过旧太刀的 mhgu_r_bridge.nro，请退出游戏后将该文件移出 nativeNX/plugins 并备份。旧桥接会在部分太刀动作中把物理 R 同时送成 R 和 ZR，导致连段漏输入。本模组的 R／ZR 互换由自己的可选插件提供。

按键见《安装与按键说明.txt》。需要互换 R／ZR 时，请选择对应平台的同版本可选补丁。模拟器和 Switch 构建沿用 Forge 绘制护腕、提示与前景特效。Vulkan 屏幕径向模糊、折射以及超宽界面锚点接口由 Windows Recomp 后处理程序提供。
