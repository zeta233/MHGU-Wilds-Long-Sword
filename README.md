# 荒野太刀 · 凌越扩展 · MHGU Recomp

将《怪物猎人 荒野》的太刀动作移植到 MHGU，支持公会与勇气风格。公会可使用特殊纳刀、居合和见切。勇气使用原生纳刀，蓝刃可使用刚气刃 GP、赤刃连段和消耗勇气槽的红刃见切。

## 安装与按键

保存并退出游戏，使用 Windows 版 MHGU Recomp 0.17.9 和 Switch Forge v1.5.1 前置。将完整安装包中的 Wilds-LS-World 文件夹解压到游戏的 mods 目录。更新前先将旧版移出 mods 备份。Windows 的追击二刀增强冲击模糊和刀身热浪折射使用 v0.293 的 Recomp 后处理补丁。

[Windows、安卓、Eden 与 Switch 发布包](https://github.com/zeta233/MHGU-Wilds-Long-Sword/releases/latest) · [安装与按键说明](安装与按键说明.txt) · [Recomp 后处理补丁](recomp-0.17.9/README.md)

Android Recomp 可通过 Files 页导入安卓完整包。v0.271 已在荣耀 Magic8 Pro 上用 MHGU Relink 0.2.1（Forge 2.0.0）和 2808×1256 分辨率完成真机复测。 [安卓 Recomp 安装说明](安卓Recomp安装说明.txt)

v0.326 的改动主要在 Windows Recomp 复测。安卓、Eden 与 Switch 兼容包已完成构建和附件校验。Switch 实体机曾报告进入集中模式、空挥居合或见切时闪退，当前实体机状态待复测。

## 编译插件

运行环境为 Windows PowerShell。准备 Rust nightly 和 rust-src、cargo-forge（MHGU Switch Forge 工具链），并将 arm-none-eabi-gcc 和 cargo 加入 PATH。依赖版本记录于 integration/Cargo.lock。本次构建使用 xPack Arm GNU Toolchain 15.2.1。

在仓库根目录运行：

```powershell
.\scripts\build.ps1
```

安卓 Recomp 插件使用 `.\scripts\build.ps1 -Platform Android` 构建。安卓动作档与握刀表由 `wilds-port/tools/build_android_charge_poses.py` 生成，请配合该插件使用。

输出为 integration/mhw_ls_rebuild.nro，安装位置为 Wilds-LS-World/romfs/nativeNX/plugins/。integration/c 包含战斗与输入逻辑和编译所需的生成表，integration/src 包含 Rust 入口。

wilds-port/tools 提供动作、战斗表和音效转换工具。重新制作资源时需另备相应游戏数据与模型，工具的默认目录结构见 portkit.py，可用 MHGU_DATA_ROOT 指定数据根目录。编译插件时已包含所需表格。
